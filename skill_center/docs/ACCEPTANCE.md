## 明确限制

- 管理版不调用模型、不解析任务附件、不执行脚本；运行就绪状态保持未验证。
- 无公开分享链接、私有 GitHub 来源或定时自动更新。
- 草稿显式保存；文件版本与元数据冲突会提示，不自动合并。
- 资源检查依赖可识别的相对引用，动态依赖仍需人工核对。
- 超出配置限额的仓库应使用单技能 ZIP 或由管理员调整限额；不会静默丢弃文件。
- YAML 别名不能通过当前预览解析器发布，但原始文件字节可保留与导出。
